# TauGrid v0.4.2

TauGrid v0.4.2 publishes the `tau` and `tau-gen` command-line tools together
with aligned TauGrid 0.4.2 images and Helm charts.

## Highlights

- Upgrade the bundled Kueue chart and controller to 0.19.2.
- Upgrade the bundled gpu-monitoring chart to 0.1.8.
- Preserve Kueue custom resource definitions when TauGrid is uninstalled or
  Kueue is disabled.

## Upgrade notes

- The deprecated `gpu-monitoring.namespace` value must remain empty. Install
  the TauGrid release with `--namespace` to move all namespaced system
  components together.
- Existing Kueue custom resources remain available when uninstalling TauGrid
  or disabling its Kueue dependency.

## Known limitations

During lifecycle-recorder initialization, an asynchronous ADX permission
assignment can fail with `AAD principal was not found` after Azure accepts
the request. The configured AzAPI retries handle matching HTTP errors but
do not restart an operation that has reached a terminal `Failed` state.
Provisioning reports an error instead of recovering automatically.

Automatic recovery of this case is not guaranteed in v0.4.2 and remains
tracked in [#161](https://github.com/Azure/taugrid/issues/161). Before an
operator retries, inspect the failed assignment and a current Terraform
plan; do not bypass Terraform ownership with manual grants or recreated
identities. This limitation does not establish a data-loss problem in
already-running ADX telemetry, or remove the need to confirm safe permission
migration during upgrades.

## Compatibility

- Public environment variables keep the `TAU_` prefix.
- Kubernetes metadata and workspace APIs keep the `tau.azure.com` domain.
- `experiment` and `portal` commands continue to require the separate
  `taugrid-portal` binary.
- The Python SDK keeps its independent package version.

## Install

Install the Tau CLI with the release quickstart script:

```bash
curl -fsSL \
  https://github.com/Azure/taugrid/releases/download/v0.4.2/install.sh | sh

export PATH="$HOME/.local/bin:$PATH"
tau version --short
```

The installer detects Linux or macOS on amd64 or arm64, verifies the published
checksums, and installs `tau` under `$HOME/.local/bin`. The matching `tau-gen`
binary and Python SDK wheel remain available as release assets.
