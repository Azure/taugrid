# TauGrid v0.4.7

TauGrid v0.4.7 aligns the `tau` and `tau-gen` command-line tools, first-party
images, and Helm charts with the workspace lifecycle fixes in #433. It includes
the security and correctness changes since the last published release, v0.4.5.

## Workspace lifecycle and authorization

- Preserve workspace routing metadata and unchanged execution identity while
  accepted workloads drain during deletion or retargeting. Discover source Jobs,
  RayJobs, RayServices, and queue-managed Deployments before derived Workloads
  exist. Long-running RayServices and Deployments must be deleted before their
  routes can be released.
- Revoke obsolete researcher access before granting replacement access, fail
  closed on revocation errors, and restore the current binding on recovery.
- Include read-only source-workload permissions in Helm and Kustomize RBAC.
- Preserve workspace authorization in repository scaffolds and reject Portal
  requests that conflict with a configured fixed workspace.

## CLI, Portal, and examples

- Validate run names, resource quantities, and resilience retry policies before
  rendering workloads, and constrain helper Pod placement for PVC operations.
- Classify cleanup context timeouts explicitly.
- Show active GPU consumers in Portal, configure fixed-workspace LocalQueues,
  and return JSON 404 responses for unknown API routes.
- Add a COBOL continued-pretraining, GRPO, and evaluation example pipeline.

## Security

- Include the v0.4.6 remediation for the compromised eMudhra intermediate CA
  keys tracked by CVE-2026-111943: Go 1.27.3, the updated runtime trust store,
  and the Portal Node.js 24.22.1 builder.
- Keep the TLS compatibility default in shipped Go binaries.

## Upgrade and compatibility

- Publish and verify the `tau`, `taugrid-portal`, `tau-core-controller`, and
  `taugrid-metrics-collector` 0.4.7 images and the coordinated 0.4.7 charts before
  publishing this GitHub release.
- Upgrade controller RBAC together with the controller image. Workspace cleanup
  deliberately waits for accepted work and long-running sources to drain.
- Replace affected v0.4.5 images rather than retagging them. Review network and
  DNS telemetry and rotate credentials that may have crossed attacker-observable
  networks while affected images were deployed.
- The Python SDK, `gpu-monitoring`, `adx-mon`, and Ray images retain their
  independent versions.

## Install

```bash
curl -fsSL \
  https://github.com/Azure/taugrid/releases/download/v0.4.7/install.sh | sh

export PATH="$HOME/.local/bin:$PATH"
tau version --short
```
