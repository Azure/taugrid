# TauGrid v0.1.1

TauGrid v0.1.1 narrows the shipped `tau` CLI surface and makes cluster
onboarding Helm-native. It is source and command compatible with v0.1.0 for the
documented `tau` verbs.

## Highlights

- Ship Stellar and the observability Portal as the separate `taugrid-portal`
  binary and image, so the `tau` CLI no longer links the web surface.
- Make `tau cluster install` and `tau cluster uninstall` thin Helm wrappers over
  the TauGrid distribution, and add installation readiness validation.
- Complete the Rune to Tau rename and remove the remaining `airun` identifiers
  from the public surface.
- Remove hidden legacy command roots and Stellar developer tooling from the
  shipped CLI.
- Centralize Tau Kubernetes metadata keys behind a shared, guarded contract.
- Clarify that TauGrid does not own StorageClasses, PVs, or PVCs, and drop
  workspace storage readiness from the workspace API.

## Compatibility

- Public environment variables keep the `TAU_` prefix.
- Kubernetes metadata and workspace APIs keep the `tau.azure.com` domain.
- Generated local state keeps `.tau` paths and `tau.*` schema identifiers.
- `experiment` and `portal` verbs now require the `taugrid-portal` binary.
  Set `TAUGRID_PORTAL_BINARY` or put `taugrid-portal` on `PATH`.
- `TauWorkspace` no longer exposes a storage field or a `StorageReady`
  condition. Platform IaC or GitOps owns durable storage.
- Repositories should pin the Go CLI and Python SDK to the same release tag.

## Install

1. Install the Python SDK from the `v0.1.1` source revision.
2. Download the matching `tau-<os>-<arch>` binary and `SHA256SUMS`.
3. Verify the checksum before installing the binary as `tau`.
4. Put the verified binary on `PATH` and run `tau version --short`.
