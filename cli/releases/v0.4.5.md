# TauGrid v0.4.5

TauGrid v0.4.5 publishes the `tau` and `tau-gen` command-line tools together
with aligned TauGrid 0.4.5 images and Helm charts.

## Highlights

- Add team-backed workspace quota APIs and Helm configuration, including
  `TauTeam` resources, Kueue Cohorts, and per-workspace managed ClusterQueues
  and LocalQueues.
- Support multiple independently reconciled workspaces with UID-bound
  Namespace ownership, explicit adoption evidence, and fail-closed cleanup.
- Route catalog projects and run lifecycle commands through their configured
  TauWorkspace and show workspace and team quota hierarchy in the CLI.
- Show selected workspace quota and optional backing team quota in the Portal.
- Add the customer-managed Flex Azure File CSI deployment for selected AKS
  Flex nodes.

## Upgrade notes

- Upgrade the `tau-core-controller` CRDs and controller before creating
  `TauTeam` resources or team-backed workspaces.
- Team-backed workspaces use controller-managed queues named
  `tau-ws-<workspace>`. The controller stages ownership, access, workload
  identity, and queues before switching Namespace routing, then removes stale
  UID-owned resources.
- The workspace queue cutover is intentionally strict. Queue ownership
  conflicts or stale adoption evidence fail closed instead of retaining legacy
  routing or cleaning up ownerless resources.
- Publish the `tau`, `taugrid-portal`, `tau-core-controller`, and
  `taugrid-metrics-collector` images before publishing the aligned charts.

## Compatibility

- Existing workspaces that target pre-existing Namespaces must carry exact
  Namespace UID adoption evidence before the controller can take ownership.
- The Python SDK, `gpu-monitoring`, and `adx-mon` keep their independent
  release versions.

## Install

Install the Tau CLI with the release quickstart script:

```bash
curl -fsSL \
  https://github.com/Azure/taugrid/releases/download/v0.4.5/install.sh | sh

export PATH="$HOME/.local/bin:$PATH"
tau version --short
```

The shell installer detects Linux or macOS on amd64 or arm64, verifies the
published checksums, and installs `tau` under `$HOME/.local/bin`. Windows amd64
users can use the published `install.ps1`. The matching `tau-gen` binary and
independently versioned Python SDK wheel remain available as release assets.
