# TauGrid v0.4.6

TauGrid v0.4.6 publishes the `tau` and `tau-gen` command-line tools together
with aligned TauGrid 0.4.6 images and Helm charts.

## Security

- Rebuild the coordinated TauGrid images with Go 1.27.3, which rejects the
  compromised eMudhra intermediate CA keys tracked by CVE-2026-111943.
- Pin the service runtime to an Azure Linux trust-store image that rejects the
  compromised certificate chains.
- Build Portal assets with Node.js 24.22.1, which includes the corresponding
  eMudhra certificate rejection.
- Move chart, CLI, Terraform, and documentation defaults away from the affected
  TauGrid 0.4.5 images.

## Upgrade notes

- Publish the `tau`, `taugrid-portal`, `tau-core-controller`, and
  `taugrid-metrics-collector` 0.4.6 images before publishing the aligned charts.
- Replace all TauGrid 0.4.5 workloads rather than retagging existing image
  manifests.
- Review network and DNS telemetry and rotate credentials that may have crossed
  attacker-observable networks while affected images were deployed.

## Compatibility

- The Python SDK, `gpu-monitoring`, and `adx-mon` keep their independent
  release versions.
- The Portal frontend build temporarily uses the pinned official Node.js image
  because Azure Linux had not published a Node.js 24.22.1 builder when this
  remediation was prepared.

## Install

Install the Tau CLI with the release quickstart script:

```bash
curl -fsSL \
  https://github.com/Azure/taugrid/releases/download/v0.4.6/install.sh | sh

export PATH="$HOME/.local/bin:$PATH"
tau version --short
```
