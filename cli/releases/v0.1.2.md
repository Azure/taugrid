# TauGrid v0.1.2

TauGrid v0.1.2 is a patch release focused on reliable project execution,
workspace onboarding, and lifecycle cleanup.

## Highlights

- Add typed run dispatch with workspace-owned namespace and policy resolution.
- Bootstrap standalone researcher workspaces and align the Tau core controller
  with the shipped TauGrid distribution.
- Make cluster install dry-runs work offline, reset stale Helm values during
  upgrades, and skip readiness checks for disabled components.
- Ensure `tau run cancel` releases the underlying compute resources.
- Raise the script payload ceiling and stage multi-file Python projects
  correctly.
- Align Stellar experiment identity with the run metadata emitted by Tau.
- Improve install behavior on PEP 668 systems and warn when another `tau`
  binary shadows the newly installed binary.

## Compatibility

- Public environment variables keep the `TAU_` prefix.
- Kubernetes metadata and workspace APIs keep the `tau.azure.com` domain.
- Generated local state keeps `.tau` paths and `tau.*` schema identifiers.
- `experiment` and `portal` verbs continue to require the separate
  `taugrid-portal` binary.
- Repositories should pin the Go CLI and Python SDK to the same release tag.

## Install

1. Install the Python SDK from the `v0.1.2` source revision.
2. Download the matching `tau-<os>-<arch>` binary and `SHA256SUMS`.
3. Verify the checksum before installing the binary as `tau`.
4. Put the verified binary on `PATH` and run `tau version --short`.
