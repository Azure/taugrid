# TauGrid v0.1.0

TauGrid v0.1.0 is the first public release of the `tau` CLI and Python SDK.

## Highlights

- Publish reproducible `tau` and `tau-gen` binaries for Darwin and Linux on
  amd64 and arm64.
- Provide config-first Kubernetes Job and RayJob submission with Kueue queueing.
- Support Python train, eval, and serve handles through the Tau SDK.
- Include local-first experiment tracking, artifact publication, and run history.
- Use the public Go module identity `github.com/Azure/taugrid/cli`.
- Ship public examples and documentation without private infrastructure
  dependencies.

## Compatibility

- Public environment variables use the `TAU_` prefix.
- Kubernetes metadata and workspace APIs use the `tau.azure.com` domain.
- Generated local state uses `.tau` paths and `tau.*` schema identifiers.
- Repositories should pin the Go CLI and Python SDK to the same release tag.

## Install

1. Install the Python SDK from the `v0.1.0` source revision.
2. Download the matching `tau-<os>-<arch>` binary and `SHA256SUMS`.
3. Verify the checksum before installing the binary as `tau`.
4. Put the verified binary on `PATH` and run `tau version --short`.
