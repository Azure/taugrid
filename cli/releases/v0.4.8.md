# TauGrid v0.4.8

TauGrid v0.4.8 adds opt-in inventory-derived team capacity and direct batch Job
submission for team-linked workspaces without workload presets.

## Automatic team capacity

- Select one team with `TauCluster.spec.queues.capacityTeamRef.name`. Eligible
  Ready, schedulable, non-deleting GPU-class nodes contribute their allocatable
  resources once to the team's root Cohort.
- Team workspaces use zero nominal quota and derived borrowing limits, allowing
  either workspace to use the available shared pool without per-flavor totals
  or fixed workspace splits.
- Reconcile inventory growth and shrink without subtracting running Pods,
  inflating replacement capacity, or evicting accepted workloads.
- Reject overlapping team, legacy, or external budgets and conflicting retained
  reservations. Unrelated quota-free queues and Cohorts remain valid and
  unchanged. Automatic-policy failures withhold the pool's nominal budget.

## Direct Job submission

- On a Ready automatic-capacity cluster with no workload profiles, submit
  `engine: job` configs from a connected workspace belonging to the selected
  team. Require explicit `compute.gpus`; use `0` for CPU Jobs.
- Preserve verified workspace routing, normal resource validation, and suspended
  Kueue admission. GPU requests and limits equal the explicit count; no
  workload-profile identity is invented.
- Default placement to unconstrained topology-aware scheduling while preserving
  explicit placement. CPU-only Jobs use the same GPU-node pool and tolerate its
  declared taints without requesting a GPU.
- Explicit profile requests and nonempty catalogs retain profile selection.
  RayJobs, managed workflows, and offline snapshots retain their existing
  profile contracts.

## Upgrade and compatibility

- Upgrade the generated CRDs, controller RBAC, controller image, and coordinated
  charts together before setting `capacityTeamRef`.
- Automatic capacity is opt-in. Existing explicit-quota and externally owned
  configurations keep their existing behavior. The selected team and its
  workspaces must omit explicit quota; drain and remove workspace queues before
  releasing or transferring an existing pool.
- Publish and verify the `tau`, `taugrid-portal`, `tau-core-controller`, and
  `taugrid-metrics-collector` 0.4.8 images and coordinated 0.4.8 charts before
  publishing this release. Tag creation alone does not publish artifacts.
- The Python SDK, `gpu-monitoring`, `adx-mon`, and Ray images retain their
  independent versions.

## Install

```bash
curl -fsSL \
  https://github.com/Azure/taugrid/releases/download/v0.4.8/install.sh | sh

export PATH="$HOME/.local/bin:$PATH"
tau version --short
```
