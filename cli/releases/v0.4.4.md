# TauGrid v0.4.4

TauGrid v0.4.4 publishes the `tau` and `tau-gen` command-line tools together
with aligned TauGrid 0.4.4 images and Helm charts.

## Highlights

- Add controller-owned GPU topology identities for site, network domain,
  accelerator domain, and Kubernetes hostname, including provider-derived
  fabric and accelerator-island labels.
- Add `same-network-domain`, `same-accelerator-domain`, and `same-site`
  placement to the workload profile contract and immutable discovered GPU
  ResourceFlavor identities.
- Require direct Job torchrun workloads with `execution.nodes > 1` to place
  each rank pod on a distinct Kubernetes host while retaining the selected
  Kueue topology domain.
- Build and validate the release with Go 1.26.9 and `golang.org/x/net` 0.60.0,
  which include the October 2026 networking and standard-library security
  fixes.

## Upgrade notes

- Publish the `tau`, `taugrid-portal`, and `tau-core-controller` images before
  publishing the aligned charts.
- The exact Go 1.26.9 MCR builder image was not available while preparing this
  release. First-party images retain their MCR-hosted builders. The
  `tau-core-controller` builder compiles the pinned, verified Microsoft Go
  1.26.9 release-branch commit so its FIPS `systemcrypto` support is preserved;
  other builders use the verified upstream Go 1.26.9 toolchain.
- Upgrade the `tau-core-controller` CRDs and controller before submitting
  workloads that use the new topology placement values.
- Existing generic workloads using `same-network-domain` may still co-locate
  when they fit on one host. The distinct-host guarantee applies specifically
  to direct Job torchrun workloads with `execution.nodes > 1`.

## Compatibility

- The Python SDK, `gpu-monitoring`, and `adx-mon` keep their independent
  release versions.
- Multi-node direct Job torchrun now requires enough distinct eligible hosts
  inside one selected topology domain and remains pending when that capacity is
  unavailable.

## Install

Install the Tau CLI with the release quickstart script:

```bash
curl -fsSL \
  https://github.com/Azure/taugrid/releases/download/v0.4.4/install.sh | sh

export PATH="$HOME/.local/bin:$PATH"
tau version --short
```

The installer detects Linux or macOS on amd64 or arm64, verifies the published
checksums, and installs `tau` under `$HOME/.local/bin`. The matching `tau-gen`
binary and independently versioned Python SDK wheel remain available as
release assets.
