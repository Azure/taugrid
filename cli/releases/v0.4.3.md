# TauGrid v0.4.3

TauGrid v0.4.3 publishes the `tau` and `tau-gen` command-line tools together
with aligned TauGrid 0.4.3 images and Helm charts.

## Highlights

- Add the standalone `taugrid-metrics-collector` image for required queued ADX
  delivery of typed experiment metrics.
- Add typed ADX event and catalog assets plus stable Portal v2 experiment,
  run, metric catalog, and bounded series reads.
- Update the native Portal Experiments workflow to use the typed-only ADX
  contract and surface ADX or Function failures without a raw-metric fallback.

## Upgrade notes

- Publish the `tau`, `taugrid-portal`, `tau-core-controller`, and
  `taugrid-metrics-collector` images before publishing the aligned charts.
  The controller chart remains part of the coordinated release train even
  though this release does not require controller binary code changes.
- Enable the typed adx-mon table, catalogs, and stable Functions before routing
  Portal traffic or enabling metrics collector sidecars.
- The collector requires an immutable image reference, the ADX endpoint and
  database, and the TauWorkspace ServiceAccount Workload Identity client ID.

## Compatibility

- Canonical Portal v2 experiment reads are typed-only; there is no legacy,
  dual, shadow-read, or read-source switch.
- The collector runtime is `collector-v1`, delivery mode is `adx-required`,
  and the sink is `adx-queued-v1`.
- The Python SDK keeps its independent package version.

## Install

Install the Tau CLI with the release quickstart script:

```bash
curl -fsSL \
  https://github.com/Azure/taugrid/releases/download/v0.4.3/install.sh | sh

export PATH="$HOME/.local/bin:$PATH"
tau version --short
```

The installer detects Linux or macOS on amd64 or arm64, verifies the published
checksums, and installs `tau` under `$HOME/.local/bin`. The matching `tau-gen`
binary and Python SDK wheel remain available as release assets.
