[Community](../community/) sections, organized by audience instead of
persona:

## Researcher

A researcher authors and runs workloads. Start with
[Run your first target](../developer-guide/first-run/).

## Platform operator

A platform operator provides governed infrastructure and workspace policy.
Start with [Enable a workspace](../platform-admin-guide/enable-workspace/).

## On-call operator

An operator identifies the first blocked lifecycle layer. Start with
[Troubleshoot a run](../platform-admin-guide/troubleshoot/).

## Contributor or integrator

A contributor extends TauGrid or a provider boundary. Start with
[Make a compatible change](../community/change/).
